** Использование

Важно!!!!
Перед прошивкой Зубр-контроллера обязательно перевключить робота!!!
Если этого не сделать, то можно превратить Зубр-контроллер в "кирпич", который
"лечится" только прошивкой через программатор.

Программа-генератор используется для генерации исходного кода инференса по модели onnx.
Дополнительно, программа может заменить веса в файле hex. Т.е.изначально программа содержит инференс и конкретные
веса конкретной модели. Если нужно сменить только веса, то можно это сделать непосредственно в файле прошивки,
если знать адреса, по которым компилятор распределил эти веса. Эта информация достается из файла map, который
генерируется компилятором вместе с файлом hex.

./onnxGenerator.exe walk.onnx policy.cpp roboControllerBoardV6.hex roboControllerBoardV6.map roboResult.hex

где
  onnxGenerator.exe         программа-генератор
  walk.onnx                 путь к модели, из которой нужно взять веса
  policy.cpp                имя файла для генерации исходного кода инференса (для
                            смены весов - это просто затычка, оставьте это имя и
                            игнорируйте сгенерированный файл)
  roboControllerBoardV6.hex hex-файл прошивки с откомпилированной программой инференса и константами весов
  roboControllerBoardV6.map карта распределения переменных, формируется компилятором.
                            Используется программой для замены весов исходной модели (той, с которой
                            компилировался файл прошивки)
  roboResult.hex            имя файла прошивки с обновленными весами
